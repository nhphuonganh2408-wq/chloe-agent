# Signal Desk — Agent Showcase

Trang trưng bày tĩnh cho Hermes Profile `news-brief-editor`.

## Đưa lên GitHub Pages

1. Tạo một repository riêng chỉ chứa các tệp muốn công khai. Không đưa `SOUL.md`, `.env`, token, cấu hình Hermes hoặc dữ liệu nội bộ vào repository này.
2. Tải `index.html` lên thư mục gốc của repository.
3. Trong GitHub, mở **Settings → Pages**.
4. Ở **Build and deployment**, chọn **Deploy from a branch**, chọn nhánh chính (thường là `main`) và thư mục `/(root)`, rồi lưu.
5. Đợi GitHub Pages xuất bản và dùng URL mà trang Pages hiển thị.

Trang có bộ chọn ngôn ngữ Việt/English/中文. Nội dung mô phỏng được ghi rõ là minh họa; trang không có backend, không gọi Hermes và không có API key.
